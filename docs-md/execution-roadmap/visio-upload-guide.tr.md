# Visio Dosyası Yükleme Kılavuzu

Hazırlanan dosya:
- `docs-md/execution-roadmap/agent-lab-roadmap-relationships.vdx`

## Açma / Yükleme Seçenekleri

1. **Microsoft Visio (Desktop/Web) ile açma**
   - Dosyayı doğrudan açın.
   - Gerekirse `.vsdx` formatına yeniden kaydedin.

2. **Web tabanlı diyagram araçlarına yükleme**
   - Araç Visio XML (`.vdx`) destekliyorsa doğrudan import edin.
   - Desteklemiyorsa önce Visio’da açıp `.vsdx` veya `.svg` olarak export edin, sonra yükleyin.
