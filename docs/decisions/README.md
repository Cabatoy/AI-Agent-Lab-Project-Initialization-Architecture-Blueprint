# Mimari Karar Kayıtları

Bu klasör, açıkça onaylanmış mimari kararların kayıtlarını tutar. Henüz ayrı bir Architecture Decision Record (ADR) onaylanmamıştır.

Yeni bir kayıt; tarih, durum, bağlam, karar, değerlendirilen alternatifler, sonuçlar/etkiler ve onay sahibi alanlarını içermelidir. Öneriler karar kaydı olarak yayımlanmamalı; onaylanana kadar [açık sorular](../03-open-questions.md) ve [mevcut kararlar](../02-current-decisions.md) içindeki ilgili bölümlerde tutulmalıdır.
